# 任务交接卡

公共格式及状态边界遵守[知识库公共规则](../知识库公共规则.md)；本目录只维护本类型的模板和目录，不另写治理细则。

用于跨会话、跨 Agent 或未完成的长任务；“一个任务一个对话、另一对话统一发布”属于跨Agent交接，待发布改动均须建卡或续写原卡。活动任务放在各任务分支的 `active/`，发布对话按[公共规则第6节](../知识库公共规则.md#6-多agent写入与整合顺序)跨worktree/分支读取；不需要用户搬运聊天记录。

后台告警与转债资料补全接续见[活动交接卡](active/20261014-后台告警与转债资料补全交接.md)：.38原范围恢复及正常待披露运营确认已记录，旧“原18队列/活动66”不是当前结论；后续待披露复查与历史边界见原整改方案9.27，保留跟踪，不据活动0关闭全部事项。

当前现金收益本会话接续点见[活动任务卡](active/20261010-持仓现金收益.md)，含用户日利率政策、0.8.3.40已实现与验收范围、9个解析缺口、待闭环税务/异步性能及生产边界；本地计算现状以专项方案与技术架构9.1为准。

仅答疑且无待交接改动的短任务不额外建卡。发布和必要验收完成后先更新权威结论和索引，再按既有授权压缩归档；未验事项仍在原位置跟踪，不因开发结束关闭。正在开发时，卡片只由本任务维护；发布对话整合后更新其主分支副本，不能反写仍在工作的任务目录。

文件名：`YYYYMMDD-主题.md`。

```md
# 任务：主题

状态：进行中｜阻塞｜已关闭
交接阶段：开发中｜待整合｜已整合待发布｜已部署待验收｜已验收
任务标识：<任务卡相对路径＋创建基线；继承旧卡保留原标识>
负责人/对话标识：<可识别本任务的标识，不依赖完整聊天>
工作目录/分支：<本机绝对目录；任务分支；异机时注明主机及已推送分支>
Git 基线：<提交号>
最近检查点：<上海时间；当前步骤；接手/资源释放依据，无则注明未释放>

## 目标与边界

目标、允许修改的文件/章节、相关接口/字段；用户授权及限制。

## 完成证据与知识去向

代码提交/依赖提交、实际文件；测试日期/对应提交或差异/环境/范围/结果及未验项。
文档逐项：已更新及章节｜无需改及原因｜待补及缺口。
生产影响与需单独确认范围；开发完成时注明未部署。

## 整合与发布回执

由发布对话填写：纳入/未纳入原因、原任务提交→固定交接/整合提交→实际部署SHA/版本的映射、逐项线上证据及剩余项；回滚去向和重发状态保留。不能仅按卡片状态或提交祖先关系判定已发布。
```
