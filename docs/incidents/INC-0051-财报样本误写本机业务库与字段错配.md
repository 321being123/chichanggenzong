## 来源口径与修复

2025 年报官方 API 与本机库逐字段对照：`00386.HK` 三表 176 个双方有值项目一致；`00005.HK` 金融端点 9 个共同项目一致。A 股 `000001.SZ`、`000719.SZ` 的库值来自 Tushare、API 样本来自理杏仁，数值差异需逐项核对，不应全部归因于代码。

[Tushare 现金流接口](https://tushare.pro/document/2?doc_id=44)明确区分 `c_disp_withdrwl_invest`（收回投资）和 `c_recp_return_invest`（投资收益）；旧代码把后者标成前者。2025 年 `000001.SZ` 理杏仁样本分别为 864286000000 与 30272000000，Tushare 原始数据仅有后者 30272000000。原错误回退会把该数字显示成“收回投资”。另有 `000001.SZ` 归母含其他权益工具权益 551184000000、归母普通股权益 451231000000，Tushare 的 `total_hldr_eqy_exc_min_int` 只支持前者，不能标为后者。归母净利润和综合收益亦不能无依据标为普通股专属。`ps.toc`、`cfs.ioa` 在跨来源实样中存在显著口径差异，暂不从 Tushare 旧映射冒充理杏仁同名字段。

本地代码按真实来源分流：Tushare 只从原始字段读取已核实映射，错写或口径未核实的宽表列不回用；正确字段缺失时保留缺口。理杏仁宽表继续读取本身数据。Tushare 请求字段与旧标签同步拆分投资收回和投资收益；没有对本机业务库做清理或恢复。

2026-11-12 继续核查发现标准事实写入也受同一口径混淆影响：理杏仁的 `ps.npatoshopc`/`bs.tetoshopc` 是归母普通股专属，不能作为含其他权益持有者的 `net_profit_parent`/`equity_parent`。旧的 A 股净利回退及港股映射会误写这两种标准事实；代码已改为使用 `ps.npatshaoehopc`/`bs.tetshaoehopc`。`00005.HK` 银行端点的两个归母合计字段已实样返回并在单批组合请求中验证，其他金融类型的这两个字段权限尚未核实，保持缺口。以本机 `portfolio` 的原始留证、标准事实和当前报告版本交叉只读核查，`00005.HK` 有 23 条资产报告的 `equity_parent`、37 条利润报告的 `net_profit_parent` 与普通股专属数值相等而与归母合计不同；仅统计两种原始字段均有值且可直接比对的记录，不代表全库影响上限。这些报告可能参与 `stockSelectionRepository` 的净资产、年度利润及 TTM 输入；历史数据仍未恢复，生产影响未核实，禁止将本地代码修正当作存量数据已修复。

同轮反例还发现：分批合并未区分公告日/币种/财年，可能混拼同一期不同报告；仅有扩展科目时报告会被丢弃；缺批时原来标记完整，且适配器把未知重述标志硬写成 `0`。本地修复为按已有报告身份字段分组、逐报告统计返回批次、保留扩展科目、在共用数据集入口拒绝发布缺批报告并允许重试；重述未知不再伪造，历史理杏仁记录的 `0` 也不能作为比较依据。报告身份缺少来源修订标识时仍不能保证同公告日内的修订可区分。

2026-11-12 继续用发行人年报校验货币：`00005.HK` 2025 年报普通股股东净利润为 21,102 百万美元（见[汇丰年报](https://www.hsbc.com/-/files/hsbc/investors/hsbc-results/2025/annual/pdfs/hsbc-holdings-plc/260225-annual-report-and-accounts-2025.pdf)），理杏仁 `hk/company/fs/bank` 的 `q.ps.npatoshopc.t` 为 164,219,984,400，响应 `currency=USD`，约 7.7822 倍；`00386.HK` 年报同口径为 31,809 百万元（见[中国石化年报](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0322/2026032200057.pdf)），其理杏仁 `q.ps.npatoshopc.t` 为 35,392,283,850，响应 `currency=CNY`。两例均不能按响应 `currency` 直接把指标值当报告原币。比例接近汇率只构成线索，[理杏仁计算说明](https://www.lixinger.com/wiki/pe-ttm)介绍了 PE 计算中的港币换算，但未证明财报 API 每一字段的转换规则，不能据此自动反算或认定所有值均为港币。

补查同一来源的 `macro/currency-exchange-rate`，以 `2025-12-31` 为起止查询 USD→HKD 和 CNY→HKD，均返回空数组；该次结果不能提供报告期换算依据，也不能推断其他日期或整个接口不可用。

本地暂行防护：非港币或未知报告币种的港股理杏仁财报在数据集入口拒绝写入标准事实；现存报告的金额和每股数在三表服务隐藏并注明币种待核实，比例等非金额值仍可显示。选股权益、年度利润、TTM 及 PB/静态 PE 回退也对有证券代码证据的同类历史事实置空，携带币种缺口并阻止 TTM 回退旧值。`portfolio` 当前版本只读核查发现带港股代码且事实币种非 HKD 的理杏仁归母权益 435 条、归母利润 456 条，属于潜在受保护范围，不等于已逐条核实错误；其中 23 条和 37 条与误写批次 `794` 关联。`00005.HK`、`00386.HK` 已通过只读仓储验证隐藏金额及选股输入；库中原始值仍未修复，缺少原始证券代码等情形、其他消费者和生产范围尚需继续核查。此防护可能令港股采集与选股待补，不能冒充数据已恢复。

2026-11-13 发现港股分析概览还有独立宽表读取及已保存快照路径。现按报告来源和币种屏蔽未经核实的金额与每股数，公式版本改为 `hk-2`；旧快照缺乏逐报告来源证据，读取和刷新失败回退时屏蔽财报派生指标，保留行情等其他内容，直至按新公式生成。只读连接 `portfolio` 验证 `00005.HK`、`00386.HK` 各 60 个报告组币种待核实，利润、权益及经营现金流均未输出，TTM 状态为来源不可用；无业务库写入。该保护不是币种口径的最终核实，其他消费与生产范围仍需审计。

银行端点对 `000001.SZ` 2025 年报另实测 `bs.cabwcb=254225000000`、`bs.tlaatc=3390840000000`、`ps.nii=88021000000`（CNY）；三项均不在当前 CAS 字典，不能写入对应宽表或从现有三表服务展示。这是已证实的来源与模型覆盖缺口，不是仅凭截图推断。
