# INC-0039：可转债详细分析未生成与资料采集断链

状态：0.8.3.59已生产发布，308/308快照通过；全量资料补采执行中，原文解析缺口未闭环
日期：2026-10-12

## 现象、根因与同类范围

生产0.8.3.57只读复现：国泰转债127040.SZ详情404，上市列表却有115.555元价格、105.17元转股价值及9.555元强赎触发价。实际上市列表308只，仅21只有详细分析快照，287只落入备用展示。备用页面将八个详细栏目统一写成“详细分析快照尚未生成”，连已有的触发和财务结果也被隐藏。

根本原因是两条链路未接通：共享行情、公告、标准财务及日常派生计算已运行，但详细快照仅由手工单债刷新写入；原手工服务还另行采集行情/财报/公告，官方募集说明书、定期报告和评级的提取器主要只接受CNINFO且没有共用持久化PDF缓存。原快照一致性检查只检查已有快照转股价错配，没有核验全量上市对象缺快照。Web/Worker/健康定时器均active，不能据此断言详情资料已生成。

影响链路：交易所/共享行情与财务源 → 标准层及统一公告库 → 详细分析计算和资料投影 → 公开详情API → 页面栏目。旧API的404与页面备用逻辑吻合；本地恢复库同样缺国泰快照，排除了单个生产页面缓存原因。

## 修复及架构对齐

- 保留现有统一表和任务。原08:15估值Runner遍历全部目标日上市公募转债，发布`bond_analysis_snapshot`；公开详情缺失/旧快照时只读标准层组合详情，核心行情仍不完整才回退列表。页面读取不外采、不写快照。人工刷新只计算本地资料，再将原公告Runner的`analysis_inputs_targeted`排队。
- 原公告Runner增加18:15全量`analysis_inputs`，公司首次发行日前一年至目标日完成官方分页覆盖，再按水位三日重叠增量；成功窗口元数据先统一落库。公司覆盖水位共享，多债不重复发现；资料阶段/定向阶段的发布集合、质量和恢复作用域分开。来源失败不推进失败窗口水位，仍可处理已有原文。
- 官方PDF共用30天/5GiB持久化缓存，缓存损坏按未命中处理；投影保存证券身份、来源URL、内容SHA-256、解析版本和日期。募集说明书按发行窗口筛选；持有人表需完整并唯一归属，零基金不与表解析失败混用；评级仅按目标债券等级提取。实际评级日未在文本中提取时，要求同证券、同公告日、同等级的唯一已有标准日期，公告日不冒充评级日。
- 逐证券/文档保存剩余进度和下一次时间。首次真实全量资料槽位在10分钟止损后尝试3对象、剩余308，保持partial/continuation，未发全量资料分区；这暴露失败旧文件可能挡住后续证券，现以持久化attemptedCodes优先推进未尝试对象，已完成投影不重解析。10分钟是安全止损，不是业务上限；失败保留有效事实，扫描件独立标为OCR阻塞，同解析版本不反复撞同一件。快照覆盖与字段/历史文档完整度分开，空集合、目标日错位或未完成资料不冒充成功。
- PG DATE在报告期、评级和票息字段以文本返回。只读计算按目标日限制行情、财报、历史事件；复用本地交易日历，回售估计超过到期日时不返回错误日期；标准股息率单位修正为正确小数。没有新增平行事实表、金融供应商或调度器。
