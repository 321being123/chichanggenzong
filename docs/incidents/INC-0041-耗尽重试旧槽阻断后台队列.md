# INC-0041：耗尽重试旧槽阻断后台队列

状态：0.8.3.81本地修复，待标准发布与生产恢复验收。
日期：2026-10-17

## 现象与根因链路

生产0167a42/.80的Web、Worker及健康timer均active，health=ok；Worker心跳存在但无运行槽位。10-16 18:00之后18条pending逾期，包括IPO、日报、转债资料、财务、安全性及估值，不能将systemd存活当作业务恢复。

上游既有权限/质量失败→持久化旧failed槽位及next_attempt_at→listDueSlots先按时间LIMIT 20→JavaScript跳过其中19条耗尽maxAttempts旧槽及1条依赖未就绪旧槽→后续任务永远未进入候选→后台逾期告警增加。直接原因是资格过滤晚于分页；根本原因是缺少跨批次候选公平性回归；保护机制只监视进程心跳，不能证明领取队列有进展。数据库无阻塞查询，非页面请求或数据库锁导致。

## 修复与同类范围

沿现役JOB_DEFINITIONS逐任务读取maxAttempts，在SQL资格条件中通过jsonb_to_recordset匹配，再排序分页；保留领取阶段复核、依赖与质量门禁、退避及旧失败证据，不重置历史次数、不手工关闭告警，不增来源/任务/表/调度器。

核查全部28个现役任务共享同一listDueSlots入口。本次只消除耗尽重试候选占位，不声明依赖未就绪的其他分页情形已解决。原18条待执行队列及历史质量/权限恢复须分别核对。

## 验证与生产边界

真实portfolio_test事务回归覆盖21条旧failed、耗尽的pending/waiting_external、可重试三种状态、3/4次不同任务策略、LIMIT 1顺序及未来退避；事务整体回滚，不联网。规则JOB-DUE-FAIRNESS-001登记原追踪及生成矩阵。

标准发布、生产队列进展、数据分区及告警恢复待验收。港股403、历史动态信号、转债原308资料和净值旧资格缺口不因本补丁自动视为恢复。必要知识归入本事故及原任务架构段落，不新建重复方案；原未闭环证据保留。
