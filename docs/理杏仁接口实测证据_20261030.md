## 三、官方文档缺陷（实测发现）

- `macro/vix-fear-index`：官方 api-docs 里 url 写成 https://open.lixinger.com/api/cn/company/fundamental/non_financial，params 也是 fundamental 的字段；实测真实路径为 /api/macro/vix-fear-index，需 areaCode+startDate+endDate+metricsList，具体指标名文档不可考
- `macro/usdx`：官方文档 params 只有 startDate/endDate/limit，无 metricsList；返回 OHLC，非指标序列
- `cn/company`：官方文档把 pageIndex 标为必选但给了默认值 0，本地因此不校验必选参数
- `cn/company/block-deal`、`cn/company/trading-abnormal`、`cn/company/major-shareholders-shares-change`、`cn/company/senior-executive-shares-change` 等接口的 `requestExample` 里用了 `date`，但参数表没列；本地已按示例补齐参数白名单（标注“官方 requestExample 使用，参数表未列”）。
- `www.lixinger.com` 只提供网页，API 请求必须发往 `open.lixinger.com`；请求头必须声明 `Accept-Encoding: gzip...`，否则返回非 JSON 的 400。

## 五、未验边界

- 本轮只验证"最小示例请求能否拿到数据"，没有逐接口核对字段单位、分页终止条件、修订/更正语义与历史窗口；这些在接入具体业务前必须另行核对。
- 分页只覆盖 `pageIndex=0` 的首页；`total` 与实际页数的推进规则未验。
- 账号级限流（1000 次/分、36 次/秒）按官方 skill 声明配置，未通过打满额度触发 429 实测；熔断恢复由单元测试替代验证。
- 生产未验证：本轮全部为本机测试库，生产凭据与生产库未连接，未部署。
