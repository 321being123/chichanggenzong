## 已确认事实、已排除假设

- #115 根因不是「理杏仁没有数据」：HKFRS 宽表已有 `ps.da`、`ps.d_np_r`、`bs.cabb`、`bs.stl` 等列；原读取只映射了利润/收入/净资产等少量字段，且亏损分支硬编码不适用。
- #115 累计分红率原逻辑只依赖本地分红事件覆盖 `dividendCoverage`；来源年报分红金额可直接计算，不依赖该覆盖。
- #115 年化收益率根因是港股从不采集复权因子：`HK_PRICE_YEARS=1`、`NOT_APPLICABLE_DOMAINS=['adjustment']`，不是公式错误。
- #117 十年图不是查询截断：`stockAnalysisRepository` 估值查询无 LIMIT，但港股价格只采一年；X 轴 `slice(0,7)` 把 `YYYYMMDD` 截成 `2025093`。
- #118 港股安全性/现金流均值原为硬编码 `null`；自由现金流因官方现金流仅 7 个汇总项、无资本开支，不能真实计算，不能用 0 或经营现金流替代。
