# INC-0023：可转债强赎锁定期误判

状态：处理中——历史转债身份与解析门禁已补强，待 0.8.1.65 生产受控重建验收
日期：2026-09-15

## 现象与影响

豪美转债（127053）的官方公告明确 2026-05-26 至 2026-11-25 不行使提前赎回权，但强赎数学进度可能继续累计并显示“已满足待确认”。这会把锁定期内的数学结果误导成业务可执行状态。

## 根因链路

官方公告 → 公告检索 → `ops.raw_records` → `event.documents` → `event.convertible_bond_call_events` → `analytics.convertible_bond_call_latest` → 强赎监控/列表/估值/生命周期。

原链路没有强赎专用投影水位，强赎 PDF 没有稳定缓存重放，解析部分失败可随任务成功返回，状态计算没有把锁定期变成零观察日业务豁免；目标日重算也没有在事件读取处统一截断公告日。

## 直接原因、根本原因与保护机制失效原因

- 直接原因：本地业务快照中没有 127053 的强赎决定事件，统一视图只能返回数学跟踪状态。
- 根本原因：公告正文、解析质量、强赎投影水位和数学计算共用“任务成功”口径，缺少独立证据链。
- 保护机制失效：官方决定优先级虽已存在，但没有稳定的强赎事件输入；数据集分区也没有拒绝 `bond_redemption_events` 的非 `passed` 质量状态。

## 同类范围与核查结果

修复前本地 PostgreSQL 快照核查：强赎事件 228 条、强赎相关原始记录 379 条、事件解析不完整 108 条；升级前解析器记录 228 条，强赎专用文档缓存记录 0 条；127053 视图状态为 `tracking`，且无公告日期和锁定截止日。该结果证明问题属于整条公告解析链的同类缺口，不是单债个案。首次修复后复验发现 7 条 partial，继续定位出 PostgreSQL `Date` 日期归一化和正文决策日提取缺口；随后又发现同版本完整结果缺少正文决策证据、缓存公告日被时区/会议日污染，以及天创转债公告把触发观察区间末日误当锁定截止日，已增加缓存重解析队列、URL 日期兜底和“截止日不晚于决策日”证据保留与保守降级规则。最终复验：强赎事件 229 条、完整 228 条、保守 partial 1 条、旧解析器记录 0 条、公告日期错配 0 条、未收敛质量告警 1 条；127053 已返回 `business_status=waived`、公告日 `2026-05-26`、决策日 `2026-05-25` 和 `no_call_until=2026-11-25`。
