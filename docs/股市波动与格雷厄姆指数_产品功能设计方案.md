# 股市波动与格雷厄姆指数产品功能设计方案

> 文档状态：方案确认稿  
> 编制日期：2026-07-28  
> 功能入口：新增一级 Tab「股市波动」

## 1. 设计结论

第一期展示中国A股和港股的格雷厄姆指数，把指数变化转换为 20%～80% 的股票仓位梯队，并与当前持仓管理中的实际股票仓位进行比较。美股不进入第一期，后续是否增加另行确定。

本方案采用以下确定规则：

1. 格雷厄姆指数越高，股票相对国债越便宜，建议股票仓位越高。
2. 最低点对应 20% 股票仓位，最高点对应 80% 股票仓位。
3. 指数每上涨 10%，建议股票仓位提高 10 个百分点，共 7 档。
4. 采用“固定 10% 波动模式”，最高点与最低点联动，不能相互独立。
5. 图表中的最高点、最低点横线均可上下拖动；拖动任意一条时，另一条自动移动，以保持每档严格相差 10%。
6. A股同时展示“沪深300”和“中证全指”两套格雷厄姆指数，默认使用沪深300作为持仓联动基准。
7. 持仓联动默认比较当前所选账户的整体股票仓位，不自动交易。
8. 第一期只上线A股和港股，美股不显示入口、不接数据、不参与验收。

## 2. 指标定义

### 2.1 通用公式

```text
股票收益率（%） = 100 ÷ 指数市盈率

格雷厄姆指数（%）
= 股票收益率（%）- 对应市场10年期国债收益率（%）
```

页面和数据库统一使用“百分数”口径。例如 `5.06` 表示 `5.06%`，不保存成 `0.0506`。

### 2.2 第一期市场范围

| 市场 | 股票指数 | 市盈率 | 债券收益率 | 状态 |
|---|---|---|---|---|
| 中国A股 | 沪深300 | 沪深300指数 PE | 中国10年期国债收益率 | 公式已确认 |
| 中国A股 | 中证全指 | 中证全指 PE | 中国10年期国债收益率 | 公式已确认 |
| 港股 | 恒生指数 | 恒生指数 PE（恒生指数公司官方文件） | 美国十年期国债收益率替代基准 | 公式已确认 |

美股属于后续待定范围。本期不确定标普500口径和美国国债数据源，也不预留可点击的空页面。

A股计算时使用上游字段 `pe`，严格对应用户给出的“指数市盈率”。`pe_ttm`可以一并保存用于核查，但第一期不参与计算，也不允许页面在无提示的情况下自动切换口径。

### 2.3 日期对齐

以指数市盈率的交易日为计算日期：

- 优先使用同一天的10年期国债收益率；
- 当天债券数据尚未发布时，可使用不晚于该交易日的最近一条数据；
- 向前沿用最多 5 个自然日，并记录实际债券数据日期；
- 超过 5 日仍没有债券数据时，该日格雷厄姆指数标记为“数据不完整”，不生成新仓位信号；
- 任何情况下都不得使用未来日期的债券收益率。

## 3. 仓位梯队

### 3.1 固定10%波动规则

用户设定最低点 `L` 后，系统自动计算全部点位：

```text
第 n 档点位 = L × 1.1ⁿ，n = 0～6
最高点 H = L × 1.1⁶
```

仓位规则：

| 档位 | 点位 | 建议股票仓位 |
|---|---:|---:|
| 1 | `L` | 20% |
| 2 | `L × 1.1` | 30% |
| 3 | `L × 1.1²` | 40% |
| 4 | `L × 1.1³` | 50% |
| 5 | `L × 1.1⁴` | 60% |
| 6 | `L × 1.1⁵` | 70% |
| 7 | `L × 1.1⁶` | 80% |

例如最低点为 10：

| 格雷厄姆指数阈值 | 建议股票仓位 |
|---:|---:|
| 10.000 | 20% |
| 11.000 | 30% |
| 12.100 | 40% |
| 13.310 | 50% |
| 14.641 | 60% |
| 16.105 | 70% |
| 17.716 | 80% |

### 3.2 区间判断

- 当前指数低于最低点：20%。
- 当前指数达到某一档阈值：进入该档仓位。
- 当前指数位于两档之间：采用已达到的较低档仓位。
- 当前指数达到或超过最高点：80%。

例如当前指数为 `13.80`，已经达到 `13.31`、尚未达到 `14.641`，建议仓位为 50%。

### 3.3 数值限制

百分比复利阶梯要求最低点大于 0：

- 最低点必须 `> 0`；
- 保存精度为 4 位小数，页面显示 2～4 位；
- 当前格雷厄姆指数等于或低于 0 时直接按 20% 处理；
- 最高点始终由最低点和固定 10% 规则联动得出。

## 4. 最高点、最低点横线拖动

### 4.1 图表表现

历史曲线图包含：

- 格雷厄姆指数历史曲线；
- 最低点横线，标记“20%仓位”；
- 最高点横线，标记“80%仓位”；
- 中间 30%～70% 的 5 条梯队线；
- 当前指数点；
- 当前所在梯队的浅色背景区间。

最低点、最高点使用明显的拖动手柄。中间梯队线只展示计算结果，不允许单独拖动。

### 4.2 拖动最低点

用户上下拖动最低点横线时：

1. 最低点跟随鼠标实时变化；
2. 最高点实时变为 `最低点 × 1.1⁶`；
3. 中间 5 条梯队线同步重算；
4. 当前建议仓位和持仓偏差实时预览；
5. 松开鼠标后弹出“保存 / 取消”；
6. 选择保存后写入用户设置，取消则恢复拖动前数值。

### 4.3 拖动最高点

用户上下拖动最高点横线时：

```text
最低点 = 最高点 ÷ 1.1⁶
```

其余交互与拖动最低点一致。页面固定提示：

> 当前为固定10%波动模式，移动任意边界时，另一条边界会自动联动。

### 4.4 拖动精度和防误操作

- 拖动步长：0.01 个百分点；
- 拖动时显示浮动提示，例如“最高点 6.42% · 对应80%仓位”；
- 只有松开并确认保存后才持久化；
- 图表纵轴自动扩展，保证两条边界始终可见；
- 每个市场、每个指数分别保存设置，切换市场不会互相覆盖。

## 5. 页面功能

### 5.1 顶部切换

一级市场切换：

- 中国A股
- 港股

第一期不显示美股选项。

A股二级指数切换：

- 沪深300
- 中证全指

默认状态：

- 默认市场：中国A股；
- A股默认指数：沪深300；
- 持仓联动基准：当前页面选中的市场和指数。

### 5.2 当前状态卡片

显示：

| 字段 | 示例 |
|---|---|
| 当前格雷厄姆指数 | 5.06% |
| 当前指数市盈率 | 14.71 |
| 股票收益率 | 6.80% |
| 10年期国债收益率 | 1.73% |
| 建议股票仓位 | 60% |
| 实际股票仓位 | 67% |
| 仓位偏差 | 高出7个百分点 |
| 数据日期 | 2026-07-27 |
| 数据状态 | 正常 / 沿用 / 过期 / 缺失 |

### 5.3 时间范围

支持：

- 1年
- 3年
- 5年
- 10年
- 全部

各时间范围只在数据库已有足够历史时启用。港股如果第一期只接入恒生指数公司公开的最近1年PE，则只启用“1年”；取得长期历史PE授权并完成回填后，再开放3年、5年、10年和全部。

时间切换只读取数据库，不在用户查看、切换或刷新页面时调用外部数据源。

## 6. 与持仓管理联动

### 6.1 联动范围

第一期按“当前选中的持仓账户”计算，不新增跨账户合并功能。

```text
实际股票仓位
= 当前账户全部股权类持仓市值
÷ 当前账户总资产
```

计算口径复用现有持仓逻辑：

- `type = 股权`：计入股票仓位；
- `type = 债权`：不计入股票仓位；
- `type = 现金`及账户现金：计入总资产但不计入股票仓位；
- 港股市值继续按账户 `hkRate` 换算成人民币；
- 美股不属于第一期；如果账户中出现美股持仓，页面明确提示其未完成汇率核算，实际仓位仅供参考。

这里比较的是“当前账户整体股票仓位”，不是“港股市值占比”或“A股市值占比”。例如用户选择港股作为当前判断市场，就是使用港股格雷厄姆指数给出的建议仓位，检查当前账户整体股票仓位是否满足。

### 6.2 仓位提示

默认容差为 ±5 个百分点：

| 实际仓位 | 状态 | 提示 |
|---|---|---|
| 在建议仓位 ±5% 内 | 符合 | 当前仓位符合设定 |
| 高于上限 | 偏高 | 当前股票仓位高于设定 |
| 低于下限 | 偏低 | 当前股票仓位低于设定 |

示例：

> 港股格雷厄姆指数建议股票仓位为60%，允许范围55%～65%。当前账户实际股票仓位为67%，高出上限2个百分点。

第一期只提示，不自动生成个股买卖清单，不执行交易。

### 7.3 总结

**当前项目的数据链路还不能直接上线第一期，但A股和港股需要的数据范围已经明确。**

目前可直接复用：

- 沪深300行情和 PE；
- 中证全指行情；
- 恒生指数行情；
- 恒生指数公司提供的恒指历史PE入口；
- Tushare `us_tycr.y10` 美国十年期国债收益率作为港股估值利率替代基准；
- A股、港股持仓分类、港币汇率和整体股票仓位计算；
- Tushare客户端、定时任务、任务锁、PostgreSQL和数据质量记录架构。

上线A股完整功能前至少还要补齐：

1. 中证全指每日 PE；
2. 中国10年期国债收益率。

上线港股功能前还要完成：

1. 接入恒生指数公司最近1年的历史PE并确认每日增量方式；
2. 接入并校验 `US/10/tushare_us_tycr` 美国十年期国债收益率数据；
3. 如果第一期要求展示超过1年的港股历史，需取得恒生指数公司、CEIC、Wind或其他授权数据源的长期历史PE。

美股整体移至后续待定范围，不阻塞第一期。

## 8. 数据源补齐方案

### 8.1 中国10年期国债收益率

优先方案：

1. 为当前 Tushare 账号开通 `yc_cb` 权限；
2. 开通后先验证字段、单位、历史范围、单次限量和更新时点；
3. 验证通过后继续复用项目现有 Tushare HTTP 客户端。

备选方案：

- 使用中国债券信息网/中央国债登记结算公司提供的中国国债收益率曲线；
- 当前官方页面可查询10年期数据，历史可追溯，但生产自动化使用前需要确认稳定接口和数据授权；
- 不采用无授权的页面高频抓取作为长期正式数据源。

### 8.2 中证全指 PE

优先使用中证指数有限公司的官方指数估值数据。接入前必须实际验证：

- 是否提供 `000985.CSI` 每日 PE 历史；
- PE定义和本方案是否一致；
- 是否有稳定机器接口或授权下载方式；
- 更新时点和历史覆盖；
- 是否允许生产系统长期使用。

若官方渠道不能稳定自动获取，第一期A股只上线“沪深300”，中证全指显示“数据源待接入”，不能用成分股 PE 简单平均值冒充指数 PE。

### 8.3 港股

恒生指数 PE：

- 主数据源使用恒生指数公司官网的 Historical PE Ratio；
- 公开网站目前提供恒生指数最近1年的历史PE，下载文件按月末日期提供；
- 官网文件本次实测于 2026-07-31 更新，内容最新日期为 2026-07-30；
- 注册 Hang Seng INdex360 后可取得更多指数数据，但历史长度、自动下载方式和公开展示授权需要在开发前确认；
- 系统按月度数据处理，不把月度文件错误当作每日数据，也不虚构文件未提供的日期。

港股格雷厄姆利率替代基准：

- 使用美国十年期国债收益率作为港股估值利率替代基准；
- 数据写入 `market.sovereign_yield_daily` 的 `US/10/tushare_us_tycr`，港股计算时映射读取；
- 美国十年期国债收益率按 Tushare 交易日增量同步；恒指 PE 是官方月度数据，任务保留 45 天新鲜度窗口。

若第一期只展示最近1年，恒生指数公司公开数据可以满足PE历史起点。若第一期必须展示3年、5年或10年港股曲线，则需要购买或取得长期历史PE授权。

### 8.4 美股

美股暂不进入第一期，不接入指数PE、美国10年期国债收益率和美元汇率，也不显示空Tab。后续重新确认需求后再单独设计。

## 9. 数据更新与存储

### 9.1 首次全量

- 沪深300 PE：按Tushare实际可用最早日期回填；
- 中证全指、港股：按各正式来源实际可用最早日期回填；
- 国债收益率：按正式来源可用最早日期回填；
- 格雷厄姆指数历史起点取“指数 PE 与债券收益率都有效”的较晚日期；
- 全量任务支持按年份断点续跑，不重复覆盖有效数据。

### 9.2 日常增量

- 中国市场建议每天18:30后执行；
- 港股在恒生指数公司约01:00更新后执行，利率以 Tushare 美国十年期国债收益率最新有效值为准；
- 每次重拉最近5个交易日，处理上游修正；
- 以“指标代码 + 交易日期 + 数据源”去重；
- 空结果、异常值和失败不得覆盖上一份有效数据；
- 第一次失败后允许一次定点重拉，仍失败则记录数据质量问题，不无限重试。

### 9.3 数据分层

复用项目现有 `ops.raw_records` 保存上游原始响应，并新增：

1. `market.market_valuation_daily`：指数 PE、PE_TTM和来源日期；
2. `market.sovereign_yield_daily`：国家、期限、收益率和来源日期；
3. `analytics.graham_index_daily`：股票收益率、债券收益率、格雷厄姆指数和计算版本；
4. `analytics.graham_strategy_settings`：用户、市场、指数、最低点、最高点、步长、联动账户和历史版本。

仓位梯队由最低点实时计算，不单独保存7条重复配置。每次修改设置新增版本，保留历史，不覆盖旧记录。

## 10. 接口设计

### 获取页面总览

```http
GET /api/market-volatility/overview?market=CN&benchmark=CSI300&account=账户名
```

返回：

- 当前 PE、股票收益率、国债收益率和格雷厄姆指数；
- 当前数据日期及数据状态；
- 7档阈值和建议仓位；
- 当前账户实际股票仓位；
- 偏高、符合或偏低提示。

### 获取历史曲线

```http
GET /api/market-volatility/history?market=CN&benchmark=CSI300&range=5y
```

只读取数据库，不现场访问上游。

### 保存横线设置

```http
PUT /api/market-volatility/settings
```

请求字段：

```json
{
  "market": "CN",
  "benchmark": "CSI300",
  "movedBoundary": "lower",
  "boundaryValuePct": 3.25,
  "accountName": "当前账户",
  "version": 3
}
```

服务端根据 `movedBoundary` 重新计算另一条边界及7档点位，并使用版本号防止多个页面相互覆盖。

## 11. 异常与提示

| 情况 | 页面处理 |
|---|---|
| PE缺失或小于等于0 | 不计算当日指数，显示“市盈率无效” |
| 国债收益率缺失超过5日 | 不产生新仓位信号 |
| 当日同步失败 | 展示上一有效值，并标记数据日期 |
| 当前指数低于0 | 建议仓位固定20% |
| 未设置最低点 | 引导设置，不自动猜测 |
| 未登录或无持仓 | 只展示建议仓位 |
| 当前账户总资产小于等于0 | 不计算实际仓位 |
| 账户中存在美股持仓 | 明确提示美股不属于第一期，相关市值尚未完成汇率核算 |
| 两条横线拖动后未保存 | 离开页面时丢弃预览值 |

## 12. 验收标准

1. A股页面能切换沪深300和中证全指，设置互不覆盖。
2. 最低点为10时，7档必须准确为：10、11、12.1、13.31、14.641、16.1051、17.7156。
3. 拖动最低点时，最高点始终等于 `最低点 × 1.1⁶`。
4. 拖动最高点时，最低点始终等于 `最高点 ÷ 1.1⁶`。
5. 横线松开前只预览，确认保存后刷新页面仍保持设置。
6. 当前指数越高，建议仓位只能不变或升高，不能反向下降。
7. 指数低于最低点为20%，达到或超过最高点为80%。
8. 当前账户实际股票仓位与现有持仓汇总结果一致。
9. 默认±5个百分点容差的三种提示计算正确。
10. 页面切换市场、指数和时间范围时不调用外部数据源。
11. 外部接口失败或空数据不会覆盖上一份有效记录。
12. 同一来源、同一指标、同一日期不得产生重复数据。
13. 所有数据都能追溯到来源、来源日期、抓取时间和计算版本。
14. 未补齐的数据源不得使用模拟数据或错误替代值上线。

## 14. 最终产品边界

本功能是市场估值和仓位纪律工具，不是自动交易系统。第一期不包含：

- 自动买卖；
- 个股买卖推荐；
- 根据回测自动修改最高点或最低点；
- 用模拟数据填补缺失市场；
- 多套策略同时控制同一个账户仓位。

所有指标仅用于研究和仓位管理参考，实际投资决策仍需用户独立判断。

### 16.2 同步与回填规则

1. 首次同步时，中国10年期国债从 2006-03-01 回填；中证两条指数 PE 读取官网接口返回的全部历史；港股利率读取 Tushare `us_tycr.y10`，恒指 PE 读取恒生指数公司官方文件。Tushare `index_dailybasic` 不提供恒生指数 PE。
2. 恒指公开 PE 文件只回填文件实际包含的最近一年；页面仅启用已有数据覆盖的时间范围。
3. 服务启动后立即执行一次同步；随后每天 18:45 执行。每次日常同步会重拉最近 14 个自然日，处理数据延迟与上游修订。
4. 同步以来源、市场、基准、交易日去重；失败、空值、非正 PE 或非正收益率均不得覆盖已有有效记录。
5. 格雷厄姆指数严格按本方案公式计算：`100 ÷ PE − 10年期国债收益率`。债券数据只能向前沿用最多 5 个自然日，超过时不生成该日信号。
6. 每次同步后重算已有有效 PE 与收益率配对的格雷厄姆指数；原始上游响应、来源日期、抓取时间和计算版本均保留。

### 16.3 已实现边界

- 数据同步仅在服务端任务中访问官网；页面总览和历史接口只读数据库。
