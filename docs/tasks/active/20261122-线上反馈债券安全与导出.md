## #44 根因与最小改法（待协调方复核，不实施）

1. 读端：`server/services/bondSafetyTushare.js` 的 `fetchBondSafetySourceFromDatabase()` 用 `pick(balance, 'total_cur_liab', null)` 只读 `financial_reports.raw_payload`。
2. 写端：`server/dataAccess/adapters/lixingerDatasetAdapter.js` 的 `resolveFinancialReports()` 只把 `bs.ta/bs.tl/bs.tetshaoehopc/bs.gw/bs.cabb/bs.tfa` 映射为标准字段；`bs.tcl` 仅进入 `__statement_metrics`。
3. 落库：`server/repositories/stockProjectionRepository.js` 的 `syncReportRows()` 将 `__statement_metrics` 从 `raw_payload` 剥离，`writeStatementWideRow()` 写入 `fundamental.cn_balance.bs_tcl`；因此官方来源行的 `raw_payload` 永久没有 `total_cur_liab`。
4. 门禁：`server/services/bondSafetyService.js` 的财务覆盖按“三表同报告期存在”判断，`financial_coverage=1` 与字段级 `incomplete_company_count=305/310` 可以同时成立；展示和评分忠实消费空值，不是页面漏加载。
5. 最小改法（候选）：在 `loadBondSafetyFacts()` 读取同一报告期平衡表宽表 `bs_tcl`，仅在 `raw_payload.total_cur_liab` 为空时回退；不写库、不改报告期、不改评分阈值、不把缺失变 0。另需协调方确认官方 `bs.tcl` 与 Tushare `total_cur_liab` 的合并口径和金融行业豁免边界。
6. 报告期/类型：官方适配层当前固定 `report_type='1'` 并保留原 `reportType`；`loadBondSafetyFacts` 也按 `report_type='1'` 和三类同 `period_end` 读取。报告期不是本次缺字段主因，不能借跨期补齐。
7. 其他空值：`interest_coverage` 空与官方指标字典无 `ebit_to_interest` 有关（`REPORT_METRICS.indicator` 未映射，`readBondSafetyFinancials` 会整份回退原来源）；`cash_coverage` 空还可能因现金/交易性金融资产缺失或分母同时为空；`market_cap` 空属同日估值行缺失样本，均需按真实缺失保留，不伪造。
