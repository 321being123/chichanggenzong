- #78：`server/middleware/versionedStaticPages.js` 的 `PAGE_FILES` 遗漏 `/classroom.html`，导致 `?v=__APP_VERSION__` 未替换、浏览器长期命中旧版 `classroom.js` 强缓存。
- #79：
  1. `stockStatementService.sameIdentity` 对 `lixinger_official`（`update_flag: null`）一刀切拦截，且 `comparisonOf` 禁止利润/现金流表算同比；整改后非理杏仁来源仍要求双方 `update_flag='0'`，理杏仁官方双方均非明确重述 `'1'` 时可比，流量表同比需具备同报告期（非 `unknown`）、可信来源、`complete !== false` 与连续财年证据；
  2. 比较基期沿用 `isCurrencyUnverified` 港股币种校验，防止未核实币种分母参与同比；
  3. `getStockStatements` 与 `getStockStatementVersions` 统一取 `limit=48` 全口径/全报告期池参与版本摘要与比较基期（解决「季报+环比」「全部已存口径+近20期」漏基期及第 21 条后历史修订未触发 `409`）；
  4. 前端报告期下拉收敛为「全部 / 年报 / 半年报 / 季报」（仅返回数据含 `unknown` 时显示「未知」，切换无未知期股票时移除并回退 `all`），列头及状态说明报告期中文化，普通未披露（`source_not_disclosed`）与缺历史基期不再渲染行内 `!`。
