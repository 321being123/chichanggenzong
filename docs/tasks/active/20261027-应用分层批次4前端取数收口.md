### 后两页（表单型）实际做法

- `knowledge.js`：八种形态逐处改。保存草稿/发布时正文已是序列化好的 JSON 串，走入口时**透传不再二次序列化**；

  响应读取统一由 `.json()` 改为已解析的 `payload`。改完用语法树复查、并断言文件内不再有 `fetch(` 与 `.json()`。
