# 存在小站知识索引

> 范围：仅 `portfolio-server`。这是所有 Agent 的项目知识入口，不是历史资料全集。
> 更新：2026-08-28。

## 先读什么

每个任务先阅读：

1. `AGENTS.md`：强制规则与交付标准。
2. 本文件：按任务选择权威资料。
3. `governance/knowledge-map.json`：按任务描述和实际改动文件匹配必读、必更新资料与检查。

不要默认全量读取文档。根因不明、跨模块、数据、权限、安全、任务调度或部署变更时，必须扩大阅读范围。

## 权威资料

| 主题 | 权威位置 | 何时读取/更新 |
|---|---|---|
| 技术、数据、接口、任务、配置现状 | `docs/技术架构.md` | 相关开发前阅读；现状变化时就地更新 |
| 可转债功能页视觉规范 | `docs/技术架构.md` 第 5.2 节、`public/shared/style.css` | 新增或调整强赎、下修、安全性等可转债页面时必须复用 `.bond-feature-*` 规范 |
| 生产部署、回滚、验收 | `docs/生产部署流程.md` | 部署或环境变更前阅读；流程变化时更新 |
| 用户可见版本历史 | `CHANGELOG.md`、`public/changelog.json` | 发版或用户可见变化时更新 |
| 重要长期技术取舍 | `docs/decisions/README.md` | 新增不可逆或长期影响的选择时记录 ADR |
| 重大或重复故障 | `docs/incidents/README.md` | 根因、同类范围或防复发需要沉淀时记录 Incident |
| 长任务交接 | `docs/tasks/README.md` | 跨会话、跨 Agent 或未完成工作时维护任务卡 |

## 统一工作流

开始：确认项目根、Git 基线和未提交改动；按路由读取资料；记录不确定点。

诊断：从数据源、数据库、服务、接口、页面和运行环境检查完整链路；区分直接原因、根本原因与保护机制失效原因；检查同类对象和同类功能。

收尾：用实际 `git diff --name-only` 再跑一次路由；更新命中文档；重要取舍写 ADR，重大或重复问题写 Incident；运行 `npm.cmd run check:knowledge`。

## 平台约定

Git 仓库中的本索引、`AGENTS.md` 和路由表是唯一项目事实来源。平台私有 Memory 只能辅助召回，不得写入或裁决项目事实。

| 平台 | 状态 | 接入方式 |
|---|---|---|
| Codex | 已接入 | 根目录 `AGENTS.md` + 项目 `.codex/config.toml` |
| WorkBuddy | 待确认 | 先确认其项目规则加载机制，再只指向本索引 |
| CodeBuddy | 待确认 | 先确认其项目规则加载机制，再只指向本索引 |

未验证的平台不得宣称已接入，也不得复制本项目的事实到私有记忆。
