# INC-0048：已退市可转债生命周期未回写，僵尸债混入上市列表

状态：已随 0.9.1.17 发布（`3fb878bc`，2026-11-01 19:23 部署）
日期：2026-11-01
关联反馈：#17（岭南发债怎么混入了上市可转债里面了）

## 现象与影响

上市可转债列表出现早已到期退市的「岭南发债」（128044.SZ），带有冻结收盘价 71.37、涨跌幅 0.00%、成交量 0 的假行情，与真实在市转债混排，直接影响投资判断。用户反馈时指出「这个问题已经出现过很多次了」。

## 根因链路

1. Tushare `cb_basic` 实测返回 **1178 只**（含 1993 年至今全部历史），其中 **833 只有摘牌日、1177 只有到期日** —— 退市字段一直存在且覆盖完整。
2. 主同步 `syncConvertibleBondUniverse` 用 `isActiveBond(row, targetTradeDate)` 只挑「目标日仍有效」的债写入 `fundamental.convertible_bond_profiles`；已退市债被整体过滤，**它们的到期日/转股截止日/摘牌日从来没有写过主档**。同日另有「待上市」分支补主档，但没有对应的「已退市」分支。
3. 这些历史债是早年 `bond_history_upsert` 留下的空壳：`core.instruments.status='listed'`、`delist_date` 为空、profile 的 `maturity_date`/`conv_end_date` 为空。
4. 列表 universe 对缺失字段一律放行（`IS NULL OR ...`），只认「当日有行情」。而 Tushare `cb_daily` 对已到期僵尸体仍会返回一行 open/high/low=0、vol=0、close 冻结的记录，于是它当天就出现在列表里。

## 直接原因、根本原因与保护机制失效原因

- 直接原因：列表筛选用「当日有没有行情」代替「目标日是不是仍在市」。
- 根本原因：生命周期字段的写入只覆盖在市与待上市两类对象，退市对象没有回写路径，主档长期停在 `listed`。
- 保护机制失效原因：`core.instruments` 的列本身是齐的，但没有任何门禁检查「listed 的债是否具备可判定的生命周期」，缺字段不会被发现。

## 同类范围与核查结果

- 生产库 `listed` 且 `delist_date`、`maturity_date`、`conv_end_date` 三项全空的可转债 **682 只**（多数因为当天没有行情而未进列表，但行情源一旦给出冻结行就会冒出来）。
- 按 2026-10-29 分区预演：644 只有摘牌日、17 只可按到期日判定（主同步修复后自动补），19 只 Tushare 无对应记录（均为 100xxx 老代码，库内登记 `.SZ` 而 Tushare 为 `.SH`），2 只接口判定仍在市。
- 同一问题在 2026-09-04 已以另一形态出现过：INC-0007「公司财务任务重复纳入历史退市债」，当时的结论是「当前上市可转债唯一口径＝最新已发布行情日 + 生命周期有效 + 非定向/私募」。本次是同一口径在**展示链路**上没落实。

## 修复与回归证据

- 列表守门：universe 要求「到期日/转股截止日/退市日至少一项存在」，缺字段的债不进列表。
- 可追溯：被排除债券经 `fetchLifecycleUndetermined` 登记 `ops.data_quality_issues`（`cb_basic`/`lifecycle`/`lifecycle_missing`，含代码、名称、收盘价、成交量），主档补齐后自动回到列表，不在页面按名称隐藏。
- 根治：主同步新增 `isDelistedBond` 分支 + `updateBondLifecycleFacts` 批量回写（`COALESCE` 不覆盖已有值；摘牌日 ≤ 业务日落 `status='delisted'`），复用同一份 `cb_basic` 数据，不新增外部接口调用。该分支**不得**加「正股仍在市」条件 —— 转债退市常伴随正股退市（128044 正股 *ST 岭南已不在 `stock_basic(L)`），加上会把最该修的债全部漏掉（初版即因此漏修，已纠正并写入注释）。
- 生产只读验证：守门后 2026-10-29 分区 308 → 307，仅排除 128044，其余无误伤。
- 回归：`server/test/bond-lifecycle-backfill.test.js`（9 项，含真库集成：回写落 `delist_date` 与 `status=delisted`、空值不覆盖有效值、三个生命周期判定互斥）；`server/test/convertible-bond-list.test.js` 增加 3 项守门与质量登记断言。

## 防复发措施与遗留风险

- 「当前在市可转债」的唯一口径固定为：目标日 + 生命周期有效 + 非定向/私募；任何展示或任务链路不得只用「当日有行情」或历史 `bond_unified.status` 推导现役范围。
- 遗留：19 只 100xxx 老代码的市场归属错误（`.SZ` vs Tushare `.SH`）未修，因会影响持仓/交易引用，需单独立项核对后再改；2 只接口判定仍在市的债继续由守门排除并留质量记录，补权威到期证据后再落退市。
- 未验：页面与真机未实测；主同步回写在生产首次执行后的实际回写只数需在部署后核对。
