## 先读什么

每个任务先阅读：

1. `AGENTS.md`：强制规则与交付标准。
2. 本文件：按任务选择权威资料。
3. `governance/knowledge-map.json`：按任务描述和实际改动文件匹配必读、必更新资料与检查。

不要默认全量读取文档。根因不明、跨模块、数据、权限、安全、任务调度或部署变更时，必须扩大阅读范围。

## 统一工作流

开始：确认项目根、Git 基线和未提交改动；按路由读取资料；记录不确定点。

诊断：从数据源、数据库、服务、接口、页面和运行环境检查完整链路；区分直接原因、根本原因与保护机制失效原因；检查同类对象和同类功能。

收尾：用实际 `git diff --name-only` 再跑一次路由；更新命中文档；重要取舍写 ADR，重大或重复问题写 Incident；运行 `npm.cmd run check:knowledge`。
