# INC-0017：IPO发行阶段详情修复未进入生产

状态：已关闭
日期：2026-09-10

## 现象与影响

生产环境的燧原科技（688801）打新详情曾显示“所属行业：待补全、业务赛道：待补全”，发行阶段预测也仍来自旧日报，未显示当前方案要求的实时事实、待公布字段和可能涨幅区间。

## 根因链路

数据源 → 数据库 → 服务 → 接口 → 页面/任务 → 运行环境：

- 本地代码已增加发行阶段资料补全、19:30 公告刷新、19:45 日报刷新、预测区间和实时详情接口；事故发生时这些修改仍在工作区，尚未进入 `origin/master`。
- 事故发生时生产 `/health` 返回版本 `0.8.1.11`，首页静态资源仍引用 `js/ipo.js?v=0.8.1.10`；详情接口仍返回旧的 `ipo_reports` Markdown，未执行实时数据库详情分支。
- 生产新股历史接口对 688801 的行业和主营业务仍为空；当前 195 条 A 股新股中有 4 条缺行业、4 条缺主营业务，说明不是单只股票脏数据。

## 直接原因、根本原因与保护机制失效原因

- 直接原因：方案代码没有完成提交、推送、生产部署和发行资料补数闭环。
- 根本原因：只核对了版本号和本地测试，没有把线上接口、静态资源和目标股票同类集合作为发布验收门槛。
- 保护机制失效：版本号复用 `0.8.1.11`，无法仅靠 `/health` 判断 IPO 业务代码是否已上线；生产验收未强制检查详情接口是否走实时事实分支。
