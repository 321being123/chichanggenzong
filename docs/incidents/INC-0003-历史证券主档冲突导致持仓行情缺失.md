# INC-0003：历史证券主档冲突导致持仓行情缺失

状态：已关闭
日期：2026-09-02

## 现象与影响

持仓管理中部分 A 股当前价仍显示旧值，涨跌幅和当日盈亏显示为 `--`；港股和可转债正常。

## 根因链路

腾讯行情源返回正常报价 → `core.instruments` 同一数字同时存在裸代码历史主档和标准主档 → 统一身份解析判定歧义 → 腾讯行情适配器静默返回空 → 持仓页保留旧价格并缺少涨跌幅。

## 直接原因、根本原因与保护机制失效原因

直接原因是运行时仍扫描历史重复主档；根本原因是历史合并迁移只保留并标记旧 ID，没有完成物理收敛，而现行架构已要求唯一标准主档。异常被静默吞掉且持仓补行情逐只请求，扩大了表现范围和调用量。

## 同类范围与核查结果

全量核查股票、港股、可转债及证券外键，确认4,630组重复、4,717条旧主档均有唯一标准目标；另清理 `nan.SH` 和6条HTML拼接港股代码。受影响关联包括公司关系180条、可转债正股关系6条、套利事件4条；未发现交易数量、成本或账户隔离数据需要改写。

## 修复与回归证据

迁移125统一迁移外键并删除历史主档；运行时按市场规则解析标准代码；持仓与行情路由共用批量行情入口；数据库增加格式约束和同数字唯一索引；全量测试、迁移幂等演练和相关回归通过。
