# INC-0051：财报样本误写本机业务库与字段错配

状态：误写已停止并只读定位；本机数据恢复待确认，代码修复本地验证中；未部署。
日期：2026-11-12（原采集批次时间）；复核见下。

## 现象与影响

财报三表验收补样时，命令先设置 `PGDATABASE=portfolio_test`，之后读取本机 `.env` 的全部键，覆盖为 `PGDATABASE=portfolio`；进程未用测试模式或实际连接库名断言保护。该命令因此写入本机共享开发业务库 `portfolio`，此前“仅写隔离测试库”的说明错误；本地开发库并非生产库。发现后停止写库，所有本轮影响核查通过显式指定数据库及只读连接完成。

只读核查本机 `portfolio` 的 `ops.ingestion_runs`：批次 793 为 `000719.SZ` 三表输入 371 行；794 为 `00005.HK` 三表输入 120 行；795 为 `00939.HK` 资产/利润输入 96 行、现金流空且批次 degraded。合计 587 条输入不是“587 条全新数据”：写入使用 upsert 和当前版本重排，可能更新已有报告、原始记录和事实。按批次关联目前可查到 CAS 宽表 148/124/99 行，HKFRS 宽表 `00005.HK` 48/48/24 行和 `00939.HK` 48/48/0 行；`financial_facts` 分别关联 1571/402/288 行，这些数量仅是受影响关联范围，不证明全部新建。九个 financial 游标均被触及，`company:1772:cashflow` 的失败信息和重试计数被写入。当前 `portfolio_test` 六张宽表均为 0 行；旧记录将本机业务库计数写成测试库计数，已更正。

批次 793 的 Tushare 原始字段被验收脚本按当时的映射派生为 `__statement_metrics` 后写入 CAS 宽表；这些派生值不是供应商独立原文。不能仅按批次删除行：原始记录的冲突更新、报告当前版本重排、事实和游标均可能覆盖已有状态。只读查询外键确认这 587 份关联报告目前被 2261 条 `financial_facts` 与 587 条六宽表记录引用，约束均为 `ON DELETE CASCADE`，直接删报告会级联删除它们；无外键的下游引用尚未穷尽。已保留现场；需在确认备份/前后镜像及并发改动后，提出逐表可核对的恢复计划，由用户确认后执行。常用本地备份目录未发现本次写前的完整数据库快照，不代表其他路径或备份系统没有；尚未验证存在可用于恢复的完整写前快照。

## 来源口径与修复

2025 年报官方 API 与本机库逐字段对照：`00386.HK` 三表 176 个双方有值项目一致；`00005.HK` 金融端点 9 个共同项目一致。A 股 `000001.SZ`、`000719.SZ` 的库值来自 Tushare、API 样本来自理杏仁，数值差异需逐项核对，不应全部归因于代码。

[Tushare 现金流接口](https://tushare.pro/document/2?doc_id=44)明确区分 `c_disp_withdrwl_invest`（收回投资）和 `c_recp_return_invest`（投资收益）；旧代码把后者标成前者。2025 年 `000001.SZ` 理杏仁样本分别为 864286000000 与 30272000000，Tushare 原始数据仅有后者 30272000000。原错误回退会把该数字显示成“收回投资”。另有 `000001.SZ` 归母含其他权益工具权益 551184000000、归母普通股权益 451231000000，Tushare 的 `total_hldr_eqy_exc_min_int` 只支持前者，不能标为后者。归母净利润和综合收益亦不能无依据标为普通股专属。`ps.toc`、`cfs.ioa` 在跨来源实样中存在显著口径差异，暂不从 Tushare 旧映射冒充理杏仁同名字段。

本地代码按真实来源分流：Tushare 只从原始字段读取已核实映射，错写或口径未核实的宽表列不回用；正确字段缺失时保留缺口。理杏仁宽表继续读取本身数据。Tushare 请求字段与旧标签同步拆分投资收回和投资收益；没有对本机业务库做清理或恢复。

## 验收与剩余边界

隔离测试库 `stock-statements-contract`、`stock-statements` 通过，新增真实 PostgreSQL 只读表达式断言，覆盖两个现金流、含其他权益/普通股、原字段缺失和官方宽表不回退；仓储 SQL 983 条可静态解析、0 失败。`000001.SZ`、`000719.SZ` 2025 年报只读复核：投资收益回读原始字段，收回投资原始字段缺失则为空，普通股专属字段不再错误取归母合计。新代码尚未提交，先前全量属于旧代码树，最终整合树需按现行发布规则复验。

源到页面对照并非四类逐字段完整验收：历史真实来源留证、不同版本及未请求字段仍有缺口；比较公式、浏览器/真机、生产数据覆盖仍未验。恢复动作必须在用户确认范围后另行执行；不能把代码读取防护当作业务库已恢复。
