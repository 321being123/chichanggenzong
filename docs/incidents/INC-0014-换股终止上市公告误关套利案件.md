# INC-0014：换股“终止上市”公告误关套利案件

状态：本地已修复，生产数据回填与部署待授权
日期：2026-09-09

## 现象与影响

生产套利公开接口中，东兴证券（案件 `208`）和信达证券（案件 `209`）消失，列表中的实时换股收益也随之消失。中金公司案件仍可见。

## 根因链路

1. 2026-09-09 08:30 的巨潮增量同步抓到了两条新公告：标题为“连续停牌直至终止上市、实施换股吸收合并的提示性公告”。这里的“终止上市”是被吸收方股票退市的实施进程，不是换股交易终止。
2. `detectUpdate()` 使用“终止”裸匹配，误将公告识别为 `a_share_swap` 的 `terminated`，并把案件 208/209 的 `event_status` 改成 `terminated`。
3. 公告角色识别和公开列表的终态兜底过滤也使用“终止”裸匹配，形成第二、第三层误杀；因此即使只恢复案件状态，列表仍可能继续隐藏。
4. 终态公告跳过条款解析，生产案件 208/209 的换股参考证券和固定换股价格未被当前重建结果保留，进一步导致实时换股收益为空或无效。

## 修复与回归证据

- `classifyDocumentRole()`、`detectUpdate()` 和控制权变更终态兜底均排除“终止上市”，仍保留“终止本次交易/终止要约”等真实终态识别。
- 公开列表 SQL 过滤改为排除“终止上市”后再识别终态，避免同类案件被兜底隐藏。
- 新增回归：东兴/信达提示性公告不关闭案件；明确“终止本次换股吸收合并交易”的公告仍识别为终止；公告角色应为 `proposal`。
- 本地定向测试：套利规则 12/12、同步 21/21、前端静态检查通过。
- 生产只读核查：案件 208/209 在 08:33（北京时间）被更新为 `terminated`；案件 208 最新文档为该提示性公告，案件 209 同样如此。修复代码尚未部署，生产数据尚未改写。

## 后续处理

- 发布版本 `0.8.0.34` 后，需在备份后将案件 208/209 恢复为进行中，并通过现有官方 PDF 重解析/案件重建恢复 `target_swap_price`、`reference_swap_price`、参考证券和实时换股收益。
- 生产数据回填属于公告更正/历史数据写入，须取得用户明确授权后执行；完成后需复核东兴、信达及全部 A 股换股案件的状态、固定条款、参考行情和实时收益。
