# INC-0024 丰茂转债强赎监控数据不完整

## 发现

2026-09-15 线上只读接口显示 `123283.SZ 丰茂转债` 的强赎观察窗口缺少 `2026-08-20`、`2026-08-19` 两条正股日线，状态为 `incomplete`。Tushare `daily` 可返回两日行情，`suspend_d` 返回空，排除真实停牌。

## 根因

`server/services/convertibleBondAnalysis.js` 的最近30日正股补水查询只声明 `$1~$3`，调用却传入第四个 `recentDays.length` 参数，PostgreSQL 报 `bind message supplies 4 parameters, but prepared statement requires 3`。任务自动重试返回空数据集摘要，旧 freshness gate 仍把已有分区判为 fresh，失败没有阻止后续成功标记。

同类审计还发现两项边界问题：转股期开始前仍可能进入 `tracking`；没有转债证据的“现金管理到期赎回”标题会被宽泛规则归为实施事件。

生产补水过程中进一步发现：历史失效正股映射仍标记为 listed（上市日期为空），以及 `suspend_d` 同日同时返回复牌/停牌两条记录；前者会阻塞全局门禁，后者会触发批量 `ON CONFLICT` 回滚。

## 修复

- 观察窗口从 `conv_start_date` 开始，转股期前返回 `not_active`，统一视图由迁移 153 修正。
- 删除多余 SQL 参数，补水后复查缺口；未完成返回 `DATASET_INCOMPLETE` 并将 `stock_daily` 分区标记 stale。
- 停牌目标按当前在市转债选择；JS/Python 公告分类排除现金管理/理财到期赎回。
- 正股补水仅纳入股票资产类别、已有上市日期且未退市的映射；停牌入库按证券+日期去重并优先保留停牌事实。
- 页面增加“暂不适用”筛选，缺口提示改为“行情/停牌证据缺失”。
