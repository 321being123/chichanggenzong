# INC-0002：可转债估值历史完整性断档

状态：已修复，持续监控
日期：2026-08-30

## 现象与影响

估值历史完整性回归从原基线的 48/50 失败：行情表有 886 个交易日，估值表只有 880 个交易日，最新估值日落后行情 4 个交易日。历史估值查询和完整性统计因此出现断档。

## 根因链路

可转债行情事实表 → `market.convertible_bond_daily_metrics` → Python 估值刷新 → `analytics.convertible_bond_valuation_daily` → `ops.sync_cursors`。

## 直接原因、根本原因与保护机制失效原因

直接原因是 6 个行情日没有生成估值结果：2 个内部断档、4 个末尾缺口。根本原因是日常刷新只根据估值游标之后的日期补偿；游标已经越过内部断档后，旧逻辑无法再次发现它。保护机制只检查“游标后的连续日期”，没有检查行情日与估值日的全量差集；历史补偿也没有明确保护游标单调性。

## 同类范围与核查结果

缺口实际日期为 2026-08-20、2026-08-21、2026-08-25 至 2026-08-28。行情源对应日期均存在，活动估值模型为 `cb-valuation-v3-train-20260727`，不是模型缺失或行情源缺数。

## 修复与回归证据

- 使用现有 `convertibleBondValuation.py backfill` 入口回填 2026-08-20 至 2026-08-28，逐交易日幂等重算，不生成实时预警。
- 刷新任务新增行情日/估值日差集检查；发现游标已越过的内部缺口时自动切换全量数据并连续回填至最新可用日。
- 历史回填更新 `ops.sync_cursors` 时改为单调推进，补旧日期不会覆盖更晚游标；空回填不会清空游标。
- 回填后实测行情 886 天 / 估值 886 天，内部缺口 0，末尾待估值 0 天，游标为 2026-08-28；估值专项回归 54/54，全量测试 105/105 通过。
- 已按授权发布生产版本 `0.6.4.39`（提交 `79c761759d7f222a9163582e9630465668eb15c2`），发布前数据库备份为 `/var/backups/portfolio_cb_valuation_before_20260830_145340.dump`（157,011,910 字节）。线上回填 7 个交易日、1,971 只正式估值；按自 2021-01-01 的完整口径复核行情/估值均为 1,371 天、缺口 0、末尾待估值 0，游标为 2026-08-28 且无错误。生产 Web、Worker、健康检查定时器均 active，健康版本为 `0.6.4.39`，估值接口已为 `stale=false`。

## 防复发措施与遗留风险

每日刷新同时依赖游标补偿和日期差集核验；完整性回归持续检查总交易日数、内部缺口、末尾滞后和最新日有效估值。若上游只发布半成品行情，任务仍按现有完整度门槛等待，不会把半成品日误写为正式估值。
