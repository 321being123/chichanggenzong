# 可转债估值功能研发方案

> 状态：待开发  
> 编写日期：2026-07-27  
> 适用项目：`portfolio-server`  
> 方案版本：`cb-valuation-v1`  
> 页面定位：可转债模块下的第三个子页面  
> 核心目标：判断当前每一只可交易转债相对跨牛熊中性公允价是低估、合理还是高估  
> 重要边界：只提供研究评价、历史曲线和风险预警，不提供买入、卖出或仓位建议

## 1. 需求背景

现有“可转债”一级模块包含：

1. **可转债安全性**：判断发行人偿债风险；
2. **可转债周期**：判断整个可转债市场所处的估值周期。

本期新增：

3. **可转债估值**：列出当前市场全部可交易转债，计算每只转债的中性公允价格、公允区间、绝对估值偏离和历史估值分位，并结合现有安全性结果给出最终估值评价。

三个模块必须保持职责分离：

- 安全性回答“这只转债有没有偿债风险”；
- 周期回答“整个转债市场目前贵不贵”；
- 估值回答“这只转债相对跨牛熊中性价格贵不贵”。

最终估值评价不能代替安全性，市场周期也不能用来合理化牛市中的普遍高溢价。

## 2. 已确认的业务原则

### 2.1 不让当前市场定义合理价格

当前市场所有转债都高溢价时，不能因为同类转债都贵，就把高溢价认定为合理。

因此：

- 中性公允价采用跨越牛熊周期的历史数据；
- 当前市场热度不参与抬高中性公允价；
- 当前同类转债比较只用于“相对市场位置”，不能决定绝对高低估；
- 系统允许某个交易日绝大多数甚至全部转债同时高估；
- 不强制每天产生固定比例的低估转债。

### 2.2 安全性只负责识别虚假低估

现有可转债安全性结果作为最终评价的前置门槛：

- 安全性好，只表示允许继续讨论估值，不增加估值分数；
- 安全性差，低价格可能是风险折价，不能直接称为低估；
- 安全性缺失时仍展示该转债，但最终评价必须提示数据不足。

### 2.3 债券评级只作反向指标

债券评级不加入公允价公式：

- 评级较低、评级下调、负面展望、列入观察名单：产生信用风险提示；
- 高评级不增加估值分数；
- 高评级不提高公允价格；
- 高评级不能覆盖现有安全性模块发现的风险。

### 2.4 高估不代表立即下跌

回测显示，高估转债在正股牛市中仍可能继续上涨。因此页面只能表达：

- 价格相对中性公允价偏高或偏低；
- 安全边际较高或较低；
- 历史上同类估值偏离的修复规律。

禁止使用：

- 建议买入；
- 建议卖出；
- 应当加仓；
- 应当减仓；
- 目标收益率；
- 预计涨跌幅。

- 输出绝对估值偏离、历史估值分位和相对市场偏离；
- 关联现有可转债安全性；
- 对评级负面信息作单向风险提示；
- 输出最终估值评价；
- 支持搜索、筛选、排序；
- 支持单券详情页；

## 5. 可交易转债范围

### 5.1 纳入条件

使用`cb_basic`和最新有效`cb_daily`确定当前可交易转债。

必须满足：

- `cb_type = CB`，不包含可交换债；
- 代码符合现有可转债代码规则；
- 上市日期不晚于估值日期；
- 退市日期为空或晚于估值日期；
- 到期日期为空或晚于估值日期；
- 转股截止日期为空或晚于估值日期；
- 停止转股日期为空或晚于估值日期；
- 正股仍处于上市状态；
- 最近有效收盘价大于0。

### 5.2 临时停牌

临时停牌但尚未退市的转债仍保留：

- 使用最近5个交易日内的最后有效行情；
- 单独显示“行情日期”；
- 行情落后超过1个交易日时显示“行情非当日”；
- 超过5个交易日没有有效行情时不计算正式估值，最终评价为“数据不足”。

### 5.3 数据一致性

同一次估值中的以下字段必须来自同一交易日：

- 可转债价格；
- 转股价值；
- 转股溢价率；
- 纯债价值；
- 纯债溢价率。

禁止将实时价格与旧的转股价值、溢价率混合。

## 6. 单券估值模型

### 6.1 模型输入

第一版只采用已经完成回测的五项输入：

1. 转股价值；
2. 纯债价值；
3. 转股价值与纯债价值之比；
4. 剩余年限；
5. 最近60个有效交易日转股价值年化波动率。

模型内部使用：

```text
X1 = ln（转股价值）
X2 = ln（纯债价值）
X3 = ln（转股价值 ÷ 纯债价值）
X4 = 剩余年限
X5 = 转股价值60日年化波动率
```

不直接加入：

- 当前市场周期；
- 当前市场中位溢价率；
- 债券信用评级；
- 正股PE、PB；
- 当前成交热度；
- 当前横向排名。

这些因素不能用于替当前市场高溢价寻找合理性。

### 6.2 价值底座

```text
价值底座 A = max（纯债价值，转股价值）
```

解释：

- 正股较弱时，纯债价值提供主要底部支撑；
- 正股较强时，转股价值成为主要基础价值；
- 取两者较高值，避免把债性和股性简单相加造成重复计算。

### 6.3 实际额外价值

```text
实际额外价值率 E = ln（当前价格 ÷ 价值底座）
```

该部分代表市场为剩余期限、正股波动性和转股选择权支付的额外价格。

### 6.4 去除每日市场情绪

对历史每个交易日计算：

```text
当日市场额外价值中位数 Mt = median（当日全部有效转债的 E）
```

单券结构性额外价值：

```text
Ri = Ei - Mt
```

模型学习：

```text
Ri = f（X1，X2，X3，X4，X5）
```

这样模型学习的是单券结构差异，不会学习“某一天整个市场都很贵，所以高溢价合理”。

### 6.5 历史中性市场基准

```text
中性市场额外价值 N = 历史每日 Mt 的中位数
```

历史中性基准必须使用训练截止日前的数据，不能使用预测日及之后的数据。

### 6.6 中性公允价

```text
预测结构性额外价值 R̂ = model（X1，X2，X3，X4，X5）

中性公允价 F = 价值底座 × e^(N + R̂)
```

### 6.7 绝对估值偏离

```text
绝对估值偏离 D = 当前价格 ÷ 中性公允价 - 1
```

示例：

```text
当前价格：125元
中性公允价：112元
绝对估值偏离：+11.61%
```

含义：当前价格比跨牛熊中性公允价高约11.61%。

### 6.8 市场热度

```text
市场热度 H = 当日全部有效转债绝对估值偏离 D 的中位数
```

```text
相对市场偏离 = 单券绝对估值偏离 D - 市场热度 H
```

市场热度只用于描述环境：

- `H > 0`：整体高于中性公允价；
- `H < 0`：整体低于中性公允价；
- 不得把`H`加回单券公允价。

### 6.9 公允区间

不能只输出一个看似精确的公允价格。

使用历史样本外预测误差确定固定边界：

| 历史误差分位 | 用途 |
|---:|---|
| 20% | 低估与偏低估边界 |
| 40% | 偏低估与合理边界 |
| 60% | 合理与偏高估边界 |
| 80% | 偏高估与高估边界 |

“公允区间”对应历史误差40%～60%的价格范围。

这些边界：

- 在模型训练时生成；
- 写入模型版本；
- 日常计算时固定；
- 不能按当天全市场重新分组。

## 7. 估值等级

### 7.1 基础估值评价

根据绝对估值偏离在历史样本外误差中的固定分位：

| 历史估值分位 | 基础评价 |
|---:|---|
| `0 ≤ Q < 20` | 低估 |
| `20 ≤ Q < 40` | 偏低估 |
| `40 ≤ Q < 60` | 合理 |
| `60 ≤ Q < 80` | 偏高估 |
| `80 ≤ Q ≤ 100` | 高估 |

该分位基于跨牛熊历史，不是当天横向排名。因此牛市中可以出现：

- 低估为0只；
- 偏低估只有少量；
- 大部分转债同时偏高估或高估。

### 7.2 安全性修正

安全性不改变公允价，只改变最终文字评价。

| 基础评价 | 安全性 | 最终估值评价 |
|---|---|---|
| 低估 | 安全、低风险 | 低估 |
| 偏低估 | 安全、低风险 | 偏低估 |
| 低估、偏低估 | 中风险 | 偏低估，但需关注安全性 |
| 低估、偏低估 | 高风险 | 风险折价，不认定为低估 |
| 合理 | 高风险 | 估值合理，但安全性高风险 |
| 偏高估、高估 | 高风险 | 偏高估/高估且安全性高风险 |
| 任意 | 未评级或未匹配 | 估值结果仅供参考，安全性数据不足 |

### 7.3 信用评级负面规则

以下任一条件触发“信用风险提示”：

- 最新信用评级为`A+`及以下；
- 最近12个月发生评级下调；
- 评级展望为负面；
- 被列入评级观察名单；
- 评级历史出现连续两次及以上下调。

处理规则：

- 基础评价为低估或偏低估时，最终评价改为“风险折价”；
- 基础评价为合理、偏高估或高估时，保留基础评价并附加“信用风险提示”；
- `AA-`、`AA`、`AA+`、`AAA`不产生任何估值加分；
- 缺少评级历史时显示“评级历史不足”，不能默认评级稳定。

信用评级阈值必须作为独立规则版本管理，不能写死在前端。

### 7.4 数据不足

任一核心字段缺失时不输出正式估值：

- 当前价格；
- 转股价值；
- 纯债价值；
- 剩余年限；
- 60日波动率；
- 可用模型版本。

最终评价：

```text
数据不足
```

缺失字段必须在诊断信息中明确列出，不能按0计算。

## 9. 估值总表

### 9.1 表格字段

| 字段 | 接口字段 | 展示规则 |
|---|---|---|
| 转债代码 | `bond_code` | 去掉交易所后缀仅用于展示，内部保留完整TS代码 |
| 转债名称 | `bond_name` | 文本 |
| 正股名称 | `stock_name` | 文本 |
| 安全性 | `safety_level` | 安全、低风险、中风险、高风险、未评级 |
| 信用风险 | `credit_warning` | 无、评级偏低、评级下调、负面展望等 |
| 当前价格 | `close` | 2位小数 |
| 转股价值 | `conversion_value` | 2位小数 |
| 纯债价值 | `bond_value` | 2位小数 |
| 转股溢价率 | `conversion_premium_pct` | 2位小数＋% |
| 价值底座 | `anchor_value` | 2位小数 |
| 剩余年限 | `remaining_years` | 2位小数 |
| 60日波动率 | `conversion_value_volatility_60d` | 2位小数＋% |
| 中性公允价 | `fair_price` | 2位小数 |
| 公允区间 | `fair_price_low / fair_price_high` | `下限～上限` |
| 绝对估值偏离 | `absolute_deviation_pct` | 正数表示高于中性公允价 |
| 历史估值分位 | `valuation_percentile` | 1位小数＋% |
| 相对市场偏离 | `relative_market_deviation_pct` | 正数表示比当前市场更贵 |
| 最终估值评价 | `final_evaluation` | 估值标签 |
| 预警状态 | `alert_level` | 无、关注、重要 |
| 行情日期 | `quote_date` | `YYYY-MM-DD` |

### 9.2 默认排序

默认排序优先级：

1. 安全或低风险的低估；
2. 安全或低风险的偏低估；
3. 合理；
4. 偏高估；
5. 高估；
6. 风险折价；
7. 数据不足。

风险折价不能因为价格低排在低估列表前面。

同一评价内按历史估值分位从低到高排序。

### 9.3 表格交互

- 所有数值列支持升降序；
- 表头固定；
- 表格区域横向滚动；
- 鼠标悬停突出当前行；
- 点击转债代码或名称进入单券详情页；
- 预警行显示简洁标识，不使用闪烁动画；
- 空值统一显示`—`；
- 数据不足的单元格不能显示为0。

## 12. 站内预警

### 12.1 预警定位

预警只报告状态变化，不给出交易指令。

允许的预警文案：

- 估值由合理进入偏高估；
- 估值进入历史高位；
- 估值偏离明显扩大；
- 安全性降为高风险；
- 最新信用评级下调；
- 当前价格处于高估区且市场整体处于高位；
- 行情或估值数据超过预期日期。

禁止的预警文案：

- 建议卖出；
- 建议买入；
- 立即止盈；
- 逢低加仓；
- 上涨空间；
- 下跌目标。

### 12.2 预警类型

| 类型 | 触发条件 | 级别 |
|---|---|---|
| 估值进入高位 | 历史分位从80%以下升至80%及以上 | 关注 |
| 估值进入极端高位 | 历史分位升至95%及以上 | 重要 |
| 估值脱离高位 | 历史分位从80%及以上降至80%以下 | 信息 |
| 估值进入低位 | 历史分位从20%及以上降至20%以下，且安全性为安全或低风险 | 关注 |
| 风险折价 | 基础评价为低估/偏低估，但安全性为高风险或触发信用风险 | 重要 |
| 安全性恶化 | 安全性档位下降 | 重要 |
| 信用评级下调 | 最新评级低于上一有效评级 | 重要 |
| 负面评级展望 | 展望变为负面或进入观察名单 | 重要 |
| 市场与单券双高 | 市场周期高位且单券历史分位≥80% | 关注 |
| 数据过期 | 估值日期落后预期交易日 | 重要 |
| 数据不足 | 核心字段从完整变为缺失 | 重要 |

“估值进入低位”只说明估值状态变化，不得表达买入含义。

### 12.3 去重规则

- 同一转债、同一预警类型、同一状态只生成一次；
- 状态没有变化时不重复生成每日预警；
- 状态恢复后允许生成恢复信息；
- 模型版本切换造成的标签变化，必须先通过版本一致性校验，不能直接触发市场预警；
- 历史回填不生成实时预警；
- 数据修复任务不生成重复预警。

### 12.4 页面展示

估值总表展示当前最高级别预警。

详情页展示预警时间线：

- 预警日期；
- 预警类型；
- 原状态；
- 新状态；
- 触发数据；
- 模型版本。

第一版只做站内查看，不做外部推送和用户自定义订阅。

## 14. 模型训练与版本管理

### 14.1 训练方式

使用项目现有Python和XGBoost环境。

年度训练流程：

1. 读取训练截止日前的历史可转债日线；
2. 计算价值底座和实际额外价值；
3. 按日去除市场整体情绪；
4. 计算模型输入；
5. 使用每5个交易日抽样，减少同一转债连续数据重复；
6. 对极端训练目标使用0.5%和99.5%分位缩尾；
7. 训练结构性额外价值模型；
8. 计算历史中性市场基准；
9. 在样本外数据上计算误差分位边界；
10. 保存模型、版本、训练范围、特征和校验值；
11. 运行回测门槛；
12. 回测通过后才允许启用新模型。

### 14.2 模型版本

建议格式：

```text
cb-valuation-v1-train-20251231
```

每个模型版本保存：

- 公式版本；
- 特征版本；
- 样本池版本；
- 训练开始日期；
- 训练截止日期；
- 训练记录数；
- 转债数量；
- 中性市场基准；
- 20%、40%、60%、80%、95%误差分位；
- 模型文件路径；
- 模型文件SHA-256；
- 回测结果；
- 启用时间；
- 是否当前有效。

### 14.3 模型启用

- 同一时间只能有一个当前有效模型；
- 模型训练成功不代表自动启用；
- 必须通过回测和数据完整性检查；
- 启用新模型前保留旧模型；
- 新模型异常时能够回退到上一版本；
- 模型回退不删除已经生成的历史估值结果。

## 16. 每日任务

### 16.1 执行顺序

```text
可转债cb_daily同步成功
→ 可转债周期计算
→ 估值输入质量检查
→ 估值模型推理
→ 关联安全性和评级负面信息
→ 生成最终评价
→ 生成预警
→ 原子发布当日估值快照
```

### 16.2 事务隔离

- 原有可转债行情同步独立提交；
- 可转债周期独立事务；
- 可转债估值独立事务；
- 预警生成独立事务；
- 估值失败不能回滚原有行情和安全性数据；
- 预警失败不能回滚估值结果。

### 16.3 失败保留

- 上游为空：不覆盖；
- 核心字段覆盖率异常：不发布；
- 模型文件缺失或校验不一致：不发布；
- 计算数量明显突降：不发布；
- 安全性快照缺失：允许发布估值，但标记安全性缺失；
- 失败后继续提供上一份完整快照；
- 管理日志记录失败日期、原因、模型版本和重试次数。

## 17. 历史回填

### 17.1 回填范围

历史估值建议从2021-01-01开始：

- 2017～2020年用于第一版训练；
- 2021年开始具备足够的样本外验证基础；
- 每个历史年度使用上一年末以前训练的模型。

### 17.2 回填顺序

1. 按年度训练对应模型；
2. 按交易日升序计算该年度全部单券估值；
3. 计算当日市场热度；
4. 计算固定历史估值分位；
5. 保存每日结果；
6. 不生成实时预警；
7. 完成后扫描日期和转债缺口；
8. 校验后推进历史回填游标。

### 17.3 历史安全性

如果缺少完整的历史时点安全性快照：

- 历史估值曲线仍可展示基础估值；
- 历史最终评价标记“历史安全性不可用”；
- 不得使用当前安全性倒填过去；
- 详情页明确区分“基础估值历史”和“最终评价历史”。

## 21. 自动化测试

### 21.1 纯算法测试

- 价值底座取纯债价值和转股价值较高者；
- 对数计算正确；
- 当前市场热度不进入公允价；
- 高市场热度下全部转债可以同时高估；
- 固定历史分位边界不受当天样本排名影响；
- 缺失字段返回数据不足；
- 无穷值、空字符串和异常数值不会进入模型；
- 公允区间上下限顺序正确。

### 21.2 安全性与评级规则测试

- 安全或低风险的低估保留；
- 高风险低价转债改为风险折价；
- 中风险低估显示风险关注；
- 高评级不增加公允价；
- 评级下调触发信用风险；
- 负面展望触发信用风险；
- 缺少评级历史不会被当作稳定；
- 安全性未匹配的转债仍在列表。

### 21.3 历史防作弊测试

- 2021年估值模型训练日期不晚于2020-12-31；
- 每个历史结果只能使用当日及以前可见的数据；
- 评级按公告日期生效；
- 模型版本切换可追溯；
- 当前安全性不能倒填历史。

### 21.4 数据库测试

- 唯一键防止重复；
- 模型版本外键有效；
- 日期和数值范围约束有效；
- 重复执行同一交易日结果一致；
- 失败事务不影响原有行情和周期数据；
- 游标不会越过失败日期；
- 模型校验值不一致时拒绝计算。

### 21.5 预警测试

- 只有跨越阈值时生成预警；
- 状态不变不重复生成；
- 恢复状态生成恢复记录；
- 历史回填不生成实时预警；
- 模型切换不误触发预警；
- 高风险低估触发风险折价预警；
- 数据过期只生成一次活动预警。

### 21.6 前端测试

- 第三个子页面可正常切换；
- URL刷新和前进、后退正确；
- 表格列与接口字段一致；
- 搜索、筛选、排序正确；
- 风险折价不会排在安全低估之前；
- 点击转债进入详情；
- 四类历史曲线能读取真实字段；
- 数据不足和过期状态正确；
- 所有接口文本经过安全转义。

## 22. 回测门槛

新模型启用前必须运行样本外回测。

现有基准结果：

### 22.1 未来总收益区分

| 持有期 | 低估组相对高估组 |
|---:|---:|
| 20个有效交易日 | +1.144% |
| 60个有效交易日 | +2.876% |
| 120个有效交易日 | +4.325% |

### 22.2 扣除价值底座变化后的估值修复

| 持有期 | 低估组相对高估组 | 方向正确率 |
|---:|---:|---:|
| 20个有效交易日 | +2.347% | 87.7% |
| 60个有效交易日 | +4.561% | 93.7% |
| 120个有效交易日 | +6.831% | 96.7% |

新模型必须满足：

- 三个周期方向全部为正；
- 60日和120日不能明显低于现有模型；
- 纯债价值不低于85元的稳健代理样本中方向仍为正；
- 单一年份不能长期、持续完全失效；
- 当前高热度市场不能被模型解释成合理；
- 若回测下降超过设定容差，不允许自动启用新模型。

回测结果只证明估值区分能力，不代表实际交易收益。

## 25. 最终产品表达

页面可以表达：

```text
当前价格：125.00元
中性公允区间：109.00～115.00元
绝对估值偏离：+11.61%
历史估值分位：84.3%
市场热度：+11.85%
相对市场：比当前市场平均便宜0.24%
安全性：低风险
最终评价：高估，但略低于当前市场整体高估程度
```

页面不可以表达：

```text
应该卖出
建议减仓
目标价115元
预计下跌10%
```

本功能的最终原则：

> 中性公允价判断绝对贵不贵，市场热度说明当前环境，安全性与评级负面信息识别虚假低估；历史曲线负责展示估值变化，预警只报告状态变化，不提供交易指令。
