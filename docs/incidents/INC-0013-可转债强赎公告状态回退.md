# INC-0013：可转债强赎公告状态回退

状态：本地已修复并验证｜生产待授权
日期：2026-09-09

## 现象与影响

洽洽转债（128135）已发布到期及停止交易公告，但强赎页曾出现“跟踪中”。到期赎回与提前赎回一样，均应显示“已公告强赎”。生产只读核查发现同类临期公告债券共 5 只：110075、123071、123072、128134、128135。

## 根因链路

官方公告 → `event.convertible_bond_call_events` → `analytics.convertible_bond_call_latest` → `/api/bond-redemption` → 页面。公告同步已将“到期兑付/停止交易”归类为 `implementation`，但统一视图原先按所有事件取最新一条；后续 `warning` 触发提示可能覆盖已有公告决策，业务状态于是退回数学计算结果 `tracking`。

## 修复

- 迁移 147 新建 `latest_decision_event`，只从 `exercise`、`implementation`、`waive`、`completion` 取最新有效决策事件，忽略仅提示性的 `warning`。
- `exercise` 与 `implementation`（含到期兑付/停止交易）统一映射为 `business_status=announced`；`calculated_status` 仍保留真实触发进度。
- 新增洽洽到期公告分类回归断言，并通过 `npm.cmd run test:all`：126 项通过、0 失败、0 跳过。

## 证据与后续

生产接口和公告事件已只读核验，当前未执行生产迁移、补数或部署。上线前需按维护窗口执行迁移 147，并复核上述 5 只债券及同类临期债状态均为 `announced`。
