# INC-0053：退市固定价未进入当前估值

状态：跟踪中
日期：2026-11-22

## 现象与影响

反馈 #42 在生产 0.9.4.13 复现。账户保留了搜特退债的退市固定价，总览却显示估值不完整。同一证券在历史净值和归因中已经有退市固定价口径。

## 根因链路

搜特退债停止转让及转股 → 持仓有保留价，账户历史日价有待核实的记录 → 当前统一估值没有接入退市价资格，优先取历史日价并与常规市场收盘日比较 → 摘要与完整账户接口把该价格标为过期 → 总览提示估值不完整。

## 直接原因、根本原因与保护机制失效原因

2026-11-15 的修复覆盖了补净值与归因。现有专项只验证这两条路径，未把同一个退市持仓送入总资产取价入口。首次处理 #42 时也只补了提示，遗漏了既有退市估值政策。

## 同类范围与核查结果

生产只读扫描正数量持仓中使用既有明确退市债代码或名称的记录，仅复现证券命中。核对了账户私有持仓价格与共享日价资格。未对主档、行情、持仓或反馈状态执行生产写入。

## 修复与回归证据

把明确退市债的账户保留价纳入当前统一估值。修复落点与回归记录见[线上反馈交接卡](../tasks/active/20261122-线上反馈40至42.md)。既有补净值和归因继续沿用保留退市价合同。

## 防复发措施与遗留风险

将同一个退市持仓同时送入当前总资产、持仓导出和旧净值链路的回归，覆盖旧价优先级、缺价格、普通证券和账户隔离。生产部署、指定账户回读和真机验收待发布环节完成。
