# INC-0011：中金现金选择权串入 H 股价格与公告漏读

状态：跟踪中
日期：2026-09-08

## 现象与影响

线上套利列表的中金公司（`601995.SH`）现金选择权显示 `18.86`，页面据此计算出 `-42.11%` 预期现金收益。用户同时发现 2026-09-07 已披露的吸收合并受理/实施相关进展和 9 月 15 日停牌公告没有进入公告链。

## 根因链路

数据源 → 数据库 → 服务 → 接口 → 页面/任务 → 运行环境

1. 巨潮官方 PDF 同一条款并列披露 A 股 `34.80/34.57 元/股` 与 H 股 `18.86/18.60 港元/股`。
2. Python 解析器只按“现金选择权价格 + 数字”匹配，未区分 A/H 市场和人民币/港币；而且任务传入的是标准代码 `601995.SH`，旧解析器没有先去掉市场后缀，导致 A/H 隔离分支未实际触发。生产最新正式报告的解析结果为 `18.86`，案件重建按最新已解析文档取值，因此错误写入 `offer_price` 和 `cash_choice_price`。
3. 腾讯行情链路没有混用：案件目标仍为 `601995.SH`，`32.58` 是 A 股报价；`03908.HK` 是独立的港股报价。
4. 巨潮同步任务 2026-09-07 21:30 已成功完成，但查询截止日为 `2026-09-07`；官方公告附件按 2026-09-08 发布日索引，故该批次没有返回。另有毫秒时间戳直接以 UTC 截日的缺陷，会把北京时间零点公告记到前一天。
5. “A股异议股东收购请求权实施公告”原先未进入条款更新角色；最新公告即使进入同步，也可能被排除在解析补偿之外。最新官方实施公告使用“行权价格”表述，原正则也无法提取 `34.57`。
6. 实测最新实施公告 PDF 的中文字体映射异常，PyMuPDF 正文无法稳定还原中文；同批最新报告书 PDF 可正常提取并解析出 `34.57`。因此实施公告作为事件、停牌和申报日期证据入库，条款重建仍以可验证的正式报告书为准。
7. 首次生产重解析又暴露出任务契约遗漏：重解析实际需要下载已入库的官方 PDF，但任务曾声明外部请求上限为 `0`，Worker 因此在首份公告前拒绝全部案件。已将 `cninfo`/`hkex` 和 600 次单批边界纳入重解析契约，并补回归检查。此前看到的巨潮 `500/500` 是本站历史来源级日保护计数，并非已确认的巨潮官方总额度；本轮取消该内部日拦截，保留20次/分钟保护，真实上游429/额度错误才写入熔断记录。

## 直接原因、根本原因与保护机制失效原因

- 直接原因：A/H 并列现金条款缺少市场和币种过滤，且标准证券代码后缀使过滤分支未被触发；公告同步按错误的 UTC/夜间自然日窗口运行。
- 根本原因：解析规则只覆盖短标题/单市场写法，没有把“同一公告多市场、多币种”和“实施公告行权价格”作为结构化场景建模；同步日期口径未封装为上海时区函数。
- 保护机制失效：价格正数和解析状态校验只能判断“格式正确”，不能发现 18.86 是港币；任务只以 HTTP/入库成功判断完成，没有针对目标证券在最近发布日的公告覆盖做质量提示。

## 同类范围与核查结果

- 已核查线上中金案件的目标主档、两套腾讯代码和最新公告链，确认不是证券身份映射或行情串源。
- 解析器同类风险覆盖所有 A/H 并列现金条款；B 股转 H 股场景保留港币解析，不套用 A 股人民币过滤。生产其他案件的历史重解析和补数需在上线后执行定向审计，不能在本地诊断阶段直接改生产数据。

## 修复与回归证据

- 已修改 A 股现金条款解析、实施公告角色分类、巨潮上海日期转换、增量同步日期口径，并将套利同步调整为每日 08:30；`0.8.0.28` 进一步统一去除解析器入参中的市场后缀并提升解析器版本至 `2.0.5`，确保历史文档强制重解析。
- 已通过定向回归：解析 12/12、适配器 17/17、规则 11/11；新增用例覆盖 A/H 并列价格、`行权价格`、巨潮毫秒时间戳和实施公告角色。
- 生产修复步骤：发布代码后，对 `case_id=208/209/210` 及同类 A/H 案件执行库内官方 PDF 重新解析/案件重建，再执行一次从现有游标到当前上海日期的增量公告同步；先备份、核对差异，失败不覆盖旧值。

## 防复发措施与遗留风险

- 继续保留来源唯一键、日期游标重叠和解析证据；增加生产审计：A 股案件现金价命中港币证据、A/H 并列条款以及最新发布日公告缺失时进入质量队列。
- 早间任务解决前一晚公告的可见性，但当天晚间发布的公告将在下一次早间任务进入；如业务要求盘后即时展示，需要另行设计第二个受 Guard 保护的同步窗口，不能临时重复调用接口。
- 代码修正已发布；公告 PDF 现在按30天、5 GiB总量上限缓存，超期或超量按最旧优先清理；定向重解析与公告增量同步完成后，需再次核对线上字段、最新公告覆盖和任务游标，实施公告 PDF 的字体映射问题保留为已知解析质量风险。
