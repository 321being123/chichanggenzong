不是缺测试、缺修复，而是**跨层约定断裂**：某一层判定"成功"，下一层没有复核成功所对应的账户、对象集合、执行资格和业务状态。四个直接证据：收益文件的账户归属跨 `await` 变化；港股补数只检查已进入审计集合的缺口；已被止损的任务能被"依赖已就绪"重新释放；测试总入口把"退出码非零且含 SKIP 文本"计为跳过。

## 4. 同轮修掉的既有缺陷（被长期跳过掩盖）
