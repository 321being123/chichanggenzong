## 现象、根因与同类范围

生产0.8.3.57只读复现：国泰转债127040.SZ详情404，上市列表却有115.555元价格、105.17元转股价值及9.555元强赎触发价。实际上市列表308只，仅21只有详细分析快照，287只落入备用展示。备用页面将八个详细栏目统一写成“详细分析快照尚未生成”，连已有的触发和财务结果也被隐藏。

根本原因是两条链路未接通：共享行情、公告、标准财务及日常派生计算已运行，但详细快照仅由手工单债刷新写入；原手工服务还另行采集行情/财报/公告，官方募集说明书、定期报告和评级的提取器主要只接受CNINFO且没有共用持久化PDF缓存。原快照一致性检查只检查已有快照转股价错配，没有核验全量上市对象缺快照。Web/Worker/健康定时器均active，不能据此断言详情资料已生成。

影响链路：交易所/共享行情与财务源 → 标准层及统一公告库 → 详细分析计算和资料投影 → 公开详情API → 页面栏目。旧API的404与页面备用逻辑吻合；本地恢复库同样缺国泰快照，排除了单个生产页面缓存原因。
