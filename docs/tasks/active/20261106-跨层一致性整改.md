## 4. 同轮修掉的既有缺陷（被长期跳过掩盖）

1. `loadAnnualDividends` 按 `period_end` 精确 join，「只有中期分红」的财年会被当成"该年一笔记录都没有"→ 零分红；改为按财年关联并新增 `year_end_implemented_count`。
2. 「已实施但每股与总额全空」的记录被 `knownFromPlanOnly` 吞成零分红；新增 `amount_unknown_count`（只认无除息日的空实施记录）。
3. 只有预案时的判零补上前提（财年已尘埃落定或方案停摆 2 年以上），刚公告的预案仍按未知。
4. `loadDividendCash` 跨来源重复计息（同一经济事件两源落库被加两遍）。
