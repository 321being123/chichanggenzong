## 已确认事实、已排除假设

- #78：`server/middleware/versionedStaticPages.js` 的 `PAGE_FILES` 遗漏 `/classroom.html`，导致 `?v=__APP_VERSION__` 未替换、浏览器长期命中旧版 `classroom.js` 强缓存。
- #79：
  1. `stockStatementService.sameIdentity` 对非理杏仁来源要求双方 `update_flag='0'`，对 `lixinger_official` 要求双方均非 `'1'`；`hasFlowPeriodBasis` 要求流量表同比具备同报告期（非 `unknown`）、可信来源、`complete !== false`、显式起始日一致（若存在）及连续财年证据（无财年时仅 A 股自然年 `CAS` 有效）；
  2. 比较基期沿用 `isCurrencyUnverified` 港股币种校验，防止未核实币种分母参与同比；
  3. `getStockStatements` 与 `getStockStatementVersions` 均以单次全量快照读取（`limit: null`）统一覆盖版本摘要、展示行与比较基期池，杜绝两路读取修订漂移、筛选漏基期（含 `annual`、`quarter`、`q1`、`q3`）及任意历史报告修订未触发 `409`；
  4. 前端报告期下拉收敛为「全部 / 年报 / 半年报 / 季报」（无未知期时移除「未知」并由 Presenter 自动按 `all` 重取），列头及状态说明报告期中文化，`source_not_disclosed` 在同比/环比/不比较下均不渲染行内 `!`。
